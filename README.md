# Expense Tracker

A modern and responsive **Expense Tracker** web application built using **HTML5, CSS3, and Vanilla JavaScript**. This application enables users to record income and expenses, categorize transactions, visualize spending through charts, and monitor their financial health in a simple and intuitive interface.
The project focuses on CRUD operations, Local Storage, data visualization, modular JavaScript, and responsive web design.

1. Project Overview

Expense Tracker is a personal finance management application that helps users keep track of their daily income and expenses. It provides a clean dashboard displaying financial summaries, spending analytics, and category-wise reports.
All transaction data is stored locally using the browser's **Local Storage**, allowing users to access their financial records even after refreshing the page.
